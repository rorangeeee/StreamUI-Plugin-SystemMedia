# StreamUI-Plugin-SystemMedia

Independent source plugin for [StreamUICore](https://github.com/rorangeeee/StreamUICore). Requires Windows x64, .NET 10 SDK and StreamUI Contracts SDK major 1.

Clone this repository to '<Core>/plugins/system-media'. Build Core first, then run:

~~~powershell
powershell.exe -NoProfile -File build.ps1 -SdkPath '<Core>/sdk/native'
~~~

The SDK is generated by 'npm run sdk:build' or 'npm run host:package' in Core. This project references only the versioned SDK assembly; it has no dependency on the Core source checkout layout. The resulting DLL and dependency file remain beside 'plugin.json'.

The plugin is loaded only after explicitly enabling it or applying a preset that requires it. It runs with the Host user's native permissions.

## Source repository and editing

Track the C# source, MediaSession.ps1, project, build.ps1, NuGet.Config and manifest. DLLs, deps.json, bin, obj and release files are local build outputs and must stay ignored. Core's `docs/REPOSITORIES.md` defines the shared repository convention; run `npm run extensions:check -- <repository>` from Core to check it.

Core loads this installed repository directly. Exit Core before updating or rebuilding native DLLs, preserve personal source changes with Git, then build and restart Core. Existing plugin settings and plugin-data stay in the Core data directory. Legacy plugin copies there are retained; use `--plugins-dir` to select that location when necessary.
